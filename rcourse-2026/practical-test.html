1.2. Hint: data preparation (optional but useful)

For Exercises 4 and 5 it can be helpful to add a few well-typed columns to the data frame. You can paste this in once, near the top of your notebook, right after loading the data: 

titanic <- titanic %>%
  mutate(
    survived = ifelse(Survived == 1, "Yes", "No") %>% factor(levels = c("No", "Yes")),
    Pclass   = factor(Pclass, labels = c("1st", "2nd", "3rd")),
    Sex      = factor(Sex),
    type     = ifelse(Age <= 17, "child", "adult") %>% factor()
  )

After running this you will have:

  • survived — a factor “No”/“Yes” (in addition to the original numeric Survived),
  • Pclass — a factor “1st”“2nd”“3rd”,
  • Sex — a factor,
  • type — a factor “child”/“adult”.

You can use either the original numeric columns or these factor versions — whichever is more convenient for the exercise.

Useful columns:

  • Survived — 0 = died, 1 = survived
  • Pclass — ticket class (1, 2, 3)
  • Sex — “male” / “female”
  • Age — age in years (contains NA values)
  • SibSp — number of siblings / spouses aboard
  • Parch — number of parents / children aboard
  • Fare — ticket price in pounds

6. Exercise 5 — A hypothesis test (harder)

We want to check whether women survived at a different rate than men on the Titanic.

Do the following:

  1. Build a contingency table of Sex against Survived using table(titanic$Sex, titanic$Survived). Print it.
  2. From this table, compute the survival proportion within each sex (hint: prop.table(your_table, margin = 1)).
  3. Run a chi-squared test of independence on the contingency table (chisq.test). Print the result.
  4. Make a bar plot in ggplot2 showing survival counts split by Sex (geom_bar(position = "dodge") with fill = factor(Survived) inside aes()).
  5. Write a one or two sentence comment in the script answering:
    • Is the difference statistically significant (look at the p-value)?
    • In plain words: did women or men survive more often, and by how much?
