2. 1. The intuition: a line through a cloud of points

A linear model is the answer to two questions:

  1. If I draw the single best straight line through this cloud, where does it go?
  2. How well does that line describe the data?

"Best" means: minimise the sum of squared vertical distances from the points to the line. Those vertical distances are called residuals. The whole game of lm() is solving that minimisation problem for you and then telling you what the line was.

3.3. 2.3 Filter and slice — a tidy 1000-row working frame

We keep only adults with a sensible height, drop rows with any NA in the columns we will use, take the first 1000 rows, then add several pre-transformed versions of the numerical predictors: Ori (original), Ctr (mean-centered), Sca (z-scored), and HeightExp (a special offset we will use in §7). 


HeightIntersect <- 146.37   # where the M and F regression lines cross; see §7

df2 <- df0 %>%
  dplyr::filter(!is.na(Age)) %>%
  na.omit() %>%
  dplyr::filter(Height > 140) %>%
  dplyr::slice_head(n = 1000) %>%
  dplyr::mutate(
    # originals (kept for reference)
    WeightOri = Weight,  HeightOri = Height,  AgeOri = Age,
    # mean-centered (subtract the mean -> the new 0 is "average")
    WeightCtr = Weight - mean(Weight, na.rm = TRUE),
    HeightCtr = Height - mean(Height, na.rm = TRUE),
    AgeCtr    = Age    - mean(Age,    na.rm = TRUE),
    # standardized (z-score -> 0 = average, 1 = +1 SD)
    WeightSca = as.numeric(scale(Weight)),
    HeightSca = as.numeric(scale(Height)),
    AgeSca    = as.numeric(scale(Age)),
    # offset at HeightIntersect (used for the §7 trick)
    HeightExp = Height - HeightIntersect
  )

Two rows:

  • (Intercept) = -86.51 kg. The model's prediction for a person with Height = 0 cm. Obviously nonsensical — nobody is 0 cm tall. The intercept here is a mathematical anchor, not a "typical" prediction. We will fix this with centering in §4.
  • Height = 0.957 kg/cm. The slope: for every extra centimetre of height, predicted weight goes up by ≈1 kg.

Each row also has:

  • Std. Error — the uncertainty around that estimate.
  • t value = Estimate / Std. Error.
  • Pr(>|t|) — the p-value: "if the true coefficient were 0, how often would we see |t| this big or bigger?"
  • The stars are just visual aliases for the p-value: *** = p<.001, ** = p<.01, * = p<.05.

4.3. 3.3 The Residuals block

Residuals:
    Min     1Q  Median     3Q    Max
-31.16  -8.68  -1.27    8.10   63.41

A residual is observed − predicted. A good model has residuals roughly symmetric around zero. Here median ≈ 0 and Q1/Q3 are similar in magnitude — symmetric. The Max = 63.4 is worrying; somebody is 63 kg heavier than the model predicts, which deserves a look.

4.4. 3.4 The model-level block

Multiple R-squared:  0.2958,	Adjusted R-squared:  0.2951

  • Residual SE = 12.92 kg — the typical prediction error.
  • F-statistic — tests "the whole model vs intercept only". Significant here (p ≪ .001), but with one predictor this test duplicates the t test for the slope.

6. 5. A categorical predictor — four contrast variants

6.1. 5.1 What is a "contrast"?

R cannot multiply the letter "F" by a coefficient. When you put a factor into lm(), R secretly converts it to a numeric contrast matrix. For a 2-level factor like Gender the default is treatment coding: 


contrasts(df2$Gender)
# F
# M  0
# F  1


  F
M 0
F 1

The first level (M) becomes the reference: its dummy is 0. F gets coded as 1. So a coefficient GenderF literally reads "the expected difference in Weight when moving from M (=0) to F (=1)".

We will fit four versions of Weight ~ Gender. All four have the same fit. Only the labels of the coefficients change.

8.4. 7.4 The intersection trick: Model 3s and Model 3x

The two regression lines (one for Males, one for Females) cross at a specific height — call it HeightIntersect. We can read it off the plot or compute it: 


# (Intercept_F - Intercept_M) / (slope_M - slope_F)
# from Model 3a (raw scale):
#   Intercept_M = -51.097
#   Intercept_F = -51.097 + 54.261 = 3.164
#   slope_M     = 0.770
#   slope_F     = 0.770 - 0.374 = 0.396
height_cross <- (3.164 - (-51.097)) / (0.770 - 0.396)
height_cross   # ~145 cm — close to HeightIntersect = 146.37 we defined earlier

9. 8. Diagnostics — is the model OK?

A linear regression rests on four assumptions:

  1. Linearity — the relationship is actually linear.
  2. Independence — observations don't share residuals.
  3. Homoscedasticity — residual variance is roughly constant.
  4. Normality of residuals — for the inferential bits (t-tests, confidence intervals) to be valid.

The performance package gives all four diagnostics in one figure: 


# install.packages("performance")
performance::check_model(model3a)

If you don't have performance installed, base R's plot.lm() gives you the classical four panels: 


par(mfrow = c(2, 2))
plot(model3a)
par(mfrow = c(1, 1))

12.3. 11.3 More predictors? A bigger model

The SWPS day-01 final example threw the kitchen sink at it:

The output is huge. With four EduLevel categories, two Gender categories and one continuous Height, the 3-way interaction model has 2 × 4 × 2 = 16 coefficients. Lesson: just because you can does not mean you should. Start simple, add a predictor only when there is a question that needs it.

13. 12. Logistic regression — a 10-minute extension

When the outcome is binary (yes/no, survived/died), use a logistic regression. Same formula syntax, different function. We switch data sets to Titanic, which the class already knows. 


titanic <- read_csv(
  "https://raw.githubusercontent.com/nt246/NTRES-6100-data-science/master/datasets/Titanic.csv",
  show_col_types = FALSE
) %>%
  mutate(
    Pclass = factor(Pclass, labels = c("1st", "2nd", "3rd")),
    Sex    = factor(Sex)
  )

m_log <- glm(Survived ~ Sex + Pclass + Age,
             data   = titanic %>% drop_na(Age),
             family = binomial)
summary(m_log)

13.1. 12.1 Reading coefficients

GLM coefficients are log-odds, not probabilities. Exponentiate to get odds ratios: 


exp(coef(m_log))
exp(confint(m_log))

A coefficient of exp(...) ≈ 0.08 for Sexmale means: "the odds of surviving are about 8% of what they are for women, holding class and age fixed" — i.e. men were much less likely to survive.
