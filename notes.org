* 1. The intuition: a line through a cloud of points

A linear model is the answer to two questions:

1. If I draw the *single best straight line* through this cloud,
   where does it go?
2. How well does that line describe the data?

"Best" means: minimise the *sum of squared vertical distances* from
the points to the line. Those vertical distances are called
*residuals*. The whole game of =lm()= is solving that minimisation
problem for you and then telling you what the line was.

** 2.3 Filter and slice — a tidy 1000-row working frame

We keep only adults with a sensible height, drop rows with any =NA=
in the columns we will use, take the first 1000 rows, then add
several /pre-transformed/ versions of the numerical predictors:
=Ori= (original), =Ctr= (mean-centered), =Sca= (z-scored), and
=HeightExp= (a special offset we will use in §7).

#+begin_src R

df2 <- df0 %>%
  dplyr::filter(!is.na(Age)) %>%
  na.omit() %>%
  dplyr::filter(Height > 140) %>%
  dplyr::slice_head(n = 1000) %>%
  dplyr::mutate(
    # originals (kept for reference)

** 3.2 The =Coefficients= table

#+begin_example
Coefficients:
             Estimate Std. Error t value Pr(>|t|)
(Intercept) -86.50984    7.99673  -10.82   <2e-16 ***
Height        0.95688    0.04674   20.47   <2e-16 ***
#+end_example

Two rows:

- =(Intercept)= = =-86.51= kg. The model's prediction for a person
  with =Height = 0 cm=. Obviously nonsensical — nobody is 0 cm tall.
  The intercept here is a *mathematical anchor*, not a "typical"
  prediction. We will fix this with *centering* in §4.
- =Height= = =0.957= kg/cm. The *slope*: for every extra centimetre
  of height, predicted weight goes up by ≈1 kg.

Each row also has:

- =Std. Error= — the uncertainty around that estimate.
- =t value= = Estimate / Std. Error.
- =Pr(>|t|)= — the p-value: "if the true coefficient were 0, how
  often would we see |t| this big or bigger?"
- The stars are just visual aliases for the p-value:
  =***= = p<.001, =**= = p<.01, =*= = p<.05.

** 3.3 The =Residuals= block

#+begin_example
Residuals:
    Min     1Q  Median     3Q    Max
-31.16  -8.68  -1.27    8.10   63.41
#+end_example

A residual is =observed − predicted=. A *good* model has residuals
roughly symmetric around zero. Here median ≈ 0 and Q1/Q3 are similar
in magnitude — symmetric. The =Max = 63.4= is worrying; somebody is
63 kg heavier than the model predicts, which deserves a look.

** 3.4 The model-level block

#+begin_example
Residual standard error: 12.92 on 998 degrees of freedom
Multiple R-squared:  0.2958,	Adjusted R-squared:  0.2951
F-statistic: 419.1 on 1 and 998 DF,  p-value: < 2.2e-16
#+end_example

- *R²* = =0.296= = ≈30 % of the variability in Weight is explained by
  Height alone. Not bad for a single predictor.
- *Residual SE* = =12.92 kg= — the typical prediction error.
- *F-statistic* — tests "the whole model vs intercept only".
  Significant here (p ≪ .001), but with one predictor this test
  duplicates the =t= test for the slope.

* 5. A categorical predictor — four contrast variants

** 5.1 What is a "contrast"?

R cannot multiply the letter "F" by a coefficient. When you put a
factor into =lm()=, R secretly converts it to a numeric *contrast
matrix*. For a 2-level factor like =Gender= the default is *treatment
coding*:

#+begin_src R

contrasts(df2$Gender)
# F
# M  0
# F  1

#+end_src

#+RESULTS:
#+begin_example
  F
M 0
F 1
#+end_example

The first level (=M=) becomes the *reference*: its dummy is 0. =F=
gets coded as 1. So a coefficient =GenderF= literally reads "the
expected difference in Weight when moving from M (=0) to F (=1)".

We will fit four versions of =Weight ~ Gender=. All four have the
same fit. Only the *labels* of the coefficients change.

** 5.2 Model 2a (treatment, default — Male reference)

** 5.6 When to use which

| Contrast type    | Intercept means                  | Use when                                                                                    |
|------------------+----------------------------------+---------------------------------------------------------------------------------------------|
| Treatment        | Mean of the *reference* category | You have a control or baseline group everyone else should be compared to.                   |
| Effect / Sum     | *Grand mean* (unweighted)        | You don't want one level to be privileged. *Especially in models with interactions* (§7).   |

The =*= shorthand expands to: =Height + Gender + Height:Gender=.

The first three rows describe the *reference category* (Males) — as
if we had fit only Male data:

- *Males* of height 0 cm weigh −51 kg (mathematical anchor).

The last two rows describe how the *Female* line *differs* from the
Male line:

- =GenderF = +54.26= : at Height = 0, Females are 54 kg *heavier*

- =Height:GenderF = −0.374= : the *Female slope* is 0.374 *less* than
  the Male slope.

So:

- Male slope: 0.770 kg/cm.
- Female slope: 0.770 + (−0.374) = *0.396 kg/cm*.

Males' weight rises more steeply with height than females'. Whether
F or M is "heavier" at any given height depends on /where on Height/
we evaluate.

data, the main-effect coefficients are nonsense. Centering puts zero
in the middle of the cloud.

** 7.4 The intersection trick: Model 3s and Model 3x

The two regression lines (one for Males, one for Females) cross at a
specific height — call it =HeightIntersect=. We can read it off the
plot or compute it:

#+begin_src R

# (Intercept_F - Intercept_M) / (slope_M - slope_F)
# from Model 3a (raw scale):
#   Intercept_M = -51.097
#   Intercept_F = -51.097 + 54.261 = 3.164
#   slope_M     = 0.770
#   slope_F     = 0.770 - 0.374 = 0.396
height_cross <- (3.164 - (-51.097)) / (0.770 - 0.396)
height_cross   # ~145 cm — close to HeightIntersect = 146.37 we defined earlier

#+end_src

#+begin_example

#+end_example

* 8. Diagnostics — is the model OK?

A linear regression rests on four assumptions:

1. *Linearity* — the relationship is actually linear.
2. *Independence* — observations don't share residuals.
3. *Homoscedasticity* — residual variance is roughly constant.
4. *Normality of residuals* — for the inferential bits (t-tests,
   confidence intervals) to be valid.

The =performance= package gives all four diagnostics in one figure:

#+begin_src R

# install.packages("performance")

* 12. Logistic regression — a 10-minute extension

When the outcome is *binary* (yes/no, survived/died), use a logistic
regression. Same =formula= syntax, different function. We switch
data sets to *Titanic*, which the class already knows.

#+begin_src R

titanic <- read_csv(
  "https://raw.githubusercontent.com/nt246/NTRES-6100-data-science/master/datasets/Titanic.csv",
  show_col_types = FALSE
) %>%
  mutate(
    Pclass = factor(Pclass, labels = c("1st", "2nd", "3rd")),
    Sex    = factor(Sex)
  )

m_log <- glm(Survived ~ Sex + Pclass + Age,
             data   = titanic %>% drop_na(Age),
             family = binomial)
summary(m_log)

#+end_src

** 12.1 Reading coefficients

GLM coefficients are *log-odds*, not probabilities. Exponentiate to
get *odds ratios*:

#+begin_src R

exp(coef(m_log))
exp(confint(m_log))

#+end_src

A coefficient of =exp(...) ≈ 0.08= for =Sexmale= means: "the odds of
surviving are about 8% of what they are for women, holding class and
age fixed" — i.e. men were *much* less likely to survive.

** 12.2 Diagnostics, plotting, reporting — all the same tools

#+begin_src R

performance::check_model(m_log)
performance::r2(m_log)                  # pseudo-R² (McFadden, Nagelkerke)

ggeffects::predict_response(m_log, terms = c("Age", "Sex", "Pclass")) %>% plot()
sjPlot::plot_model(m_log, type = "eff", terms = c("Age", "Sex"))

report::report(m_log)

#+end_src

* 13. Cheat sheet

| Goal                                         | Code                                                    |
|----------------------------------------------+---------------------------------------------------------|
| Fit a linear model                           | =lm(y ~ x, data = df)=                                  |
| Add a predictor                              | =lm(y ~ x1 + x2, data = df)=                            |
| Interaction (all main + pairwise)            | =lm(y ~ x1 * x2, data = df)=                            |
| Only the interaction term                    | =lm(y ~ x1 + x2 + x1:x2, data = df)=                    |
| Three-way interaction                        | =lm(y ~ x1 * x2 * x3, data = df)=                       |
| Remove the intercept                         | =lm(y ~ 0 + x, data = df)=                              |
| Mean-centre a predictor                      | =mutate(xc = x - mean(x, na.rm = TRUE))=                |
| Standardize                                  | =mutate(xs = as.numeric(scale(x)))=                     |
| Change reference level                       | =relevel(f, ref = "X")=                                 |
| Sum / effect coding                          | =contrasts(f) <- contr.sum(levels(f))=                  |
| Helmert coding                               | =contrasts(f) <- contr.helmert(levels(f))=              |
| Inspect current contrasts                    | =contrasts(f)=                                          |
| Coefficient table                            | =summary(model)=                                        |
| Tidy coefficient table                       | =broom::tidy(model)=                                    |
| Overall fit (R², AIC, ...)                   | =broom::glance(model)=                                  |
| Data + fitted + residuals                    | =broom::augment(model)=                                 |
| Diagnostics figure                           | =performance::check_model(model)=                       |
| Multicollinearity                            | =car::vif(model)= or =car::vif(model, type="predictor")= |
| Predictions on new data                      | =predict(model, newdata = ..., interval = "confidence")= |
| Effect plot (one term)                       | =ggeffects::predict_response(model, "x") %>% plot()=    |
| Effect plot (interaction)                    | =ggeffects::predict_response(model, c("x", "g")) %>% plot()= |
| Simple slopes                                | =reghelper::simple_slopes(model)=                       |
| Pretty model table                           | =sjPlot::tab_model(model)= / =stargazer::stargazer(model)= |
| Plain-English summary                        | =report::report(model)=                                 |
| Compare nested models                        | =anova(m_small, m_big)=                                 |
| Compare any models                           | =AIC(m1, m2, m3)= / =BIC(m1, m2, m3)=                   |
| Logistic regression                          | =glm(y ~ x, data = df, family = binomial)=              |
| Convert log-odds → odds ratios               | =exp(coef(model))=                                      |
