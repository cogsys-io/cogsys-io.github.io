1.8. Zadanie 8

Masz dane trzy liczby reprezentujące długości odcinków: 

a = 5
b = 12
c = 13

Napisz kod, który:

  1. Sprawdzi, czy z tych odcinków można zbudować trójkąt (warunek trójkąta: suma dwóch krótszych boków musi być większa od najdłuższego boku).
  2. Jeśli tak, określi czy trójkąt jest:
    • prostokątny (spełnia twierdzenie Pitagorasa: a² + b² = c² dla odpowiednio posortowanych boków)
    • równoboczny (wszystkie boki równe)
    • równoramienny (dokładnie dwa boki równe)
    • różnoboczny (żadne boki nie są równe)

Wskazówka: użyj sorted([a, b, c]) żeby posortować boki.

Przetestuj dla zestawów: [3,4,5], [2,2,2], [5,5,3], [1,2,10].

1.9. Zadanie 9

Masz dane współczynniki równania kwadratowego ax² + bx + c = 0: 

a = 1
b = -3
c = 2

Napisz kod, który obliczy i wyświetli miejsca zerowe (pierwiastki) tego równania.

Kroki:

  1. Oblicz deltę: Δ = b² - 4ac
  2. Jeśli Δ < 0: wyświetl komunikat o braku miejsc zerowych
  3. Jeśli Δ = 0: oblicz jedno miejsce zerowe: x₀ = -b / (2a)
  4. Jeśli Δ > 0: oblicz dwa miejsca zerowe:
    • x₁ = (-b - √Δ) / (2a)
    • x₂ = (-b + √Δ) / (2a)

Przetestuj dla:

  • a=1, b-3, c=2= → powinno dać x₁=1, x₂=2
  • a=1, b=2, c=1 → powinno dać x₀=-1
  • a=1, b=0, c=1 → brak rozwiązań rzeczywistych

Wskazówka: użyj import math i math.sqrt() do obliczenia pierwiastka, albo delta ** 0.5.
